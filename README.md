# 🎧 LoFiFlow — Приложение для создания эмбиентного и генеративного звука

Интерактивный веб-плеер фоновых звуков и генеративной Lo-Fi музыки. Проект создан в качестве пет-проекта для портфолио, демонстрирующего работу с Web Audio API и анимацией Canvas на чистом JavaScript без сторонних фреймворков.

## 🚀 Демо
🔗 [Открыть веб-приложение](https://lofi-flow-kappa.vercel.app/)

## 🛠 Технологии и особенности
* **Vanilla JS (ES6+)** - базовый синтаксис, асинхронная загрузка звуковых буферов, сохранение состояния в `localStorage`.
* **Web Audio API** - процедурный синтез Lo-Fi аккордов, барабанных партий, генерация винилового шума и обработка мастер-динамики с помощью `DynamicsCompressorNode`.
* **HTML5 Canvas** - процедурная анимация звездного неба (динамическая отрисовка и пересчет кадров).
* **Lucide Icons** - минималистичный иконпак для компонентов интерфейса.

## 📌 Цель проекта
Демонстрация навыков работы с веб-звуком, манипуляцией DOM, обработкой пользовательских событий и адаптивной версткой.
